# Fonts

Huron's brand fonts, self-hosted so the app never depends on an outside font service.

| File | Family | Weight | License |
|---|---|---|---|
| `BricolageGrotesque-Regular.woff2` | Bricolage Grotesque | 400 | SIL Open Font License 1.1 |
| `BricolageGrotesque-Bold.woff2` | Bricolage Grotesque | 700 | SIL Open Font License 1.1 |
| `Roboto-Regular.woff2` | Roboto | 400 | Apache License 2.0 |
| `Roboto-Bold.woff2` | Roboto | 700 | Apache License 2.0 |

Bricolage Grotesque is for headings, Roboto for everything else. The brand uses only Regular and Bold; there are no other weights.
