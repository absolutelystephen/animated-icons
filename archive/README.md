# Archive

Animation concepts that weren't chosen. They're kept for reference (for example, to rebuild one in After Effects or to bring it back later), but the app ignores this folder: only masters inside `icons/` are checked, pre-rendered and shown.

To bring a concept back, move it into its icon's folder in `icons/` and move the current master here. Each icon folder in `icons/` holds one master: the chosen animation.

| Icon | Concept | Notes |
|---|---|---|
| `decision-1` | `branch-out` | The person rises; both options slide out from behind them. 1.5 s. |
| `decision-1` | `drawn-on` | Sketched in with pen-sweep masks. 2.0 s. |
| `decision-1` | `sequential-pop` | Person, then X, then check pop in. 1.3 s. |

The chosen animation for `decision-1` is `weigh-the-options`, in `icons/decision-1/`.
